# Chemistry presentation kit

Open `slides/Chemistry-COMP3278-final.pptx`. Start with `scripts/five-minute-plan.md` and `storyboard/two-minute-demo.md`. The deck covers the first three minutes; a two-minute demonstration completes the five-minute presentation.

- `slides/`: editable PowerPoint deck, rendered previews and slide content source.
- `er-diagrams/`: simplified and detailed diagrams, editable Mermaid and Graphviz sources, SVG/PNG exports, and integrity explanation.
- `sql/`: actual ranking query, executable bound examples for other operations, presentation graphics and explanations.
- `diagrams/`: architecture, CRUD and measured personalization graphics.
- `data/rankings.json`: actual before/after MySQL results generated by integration tests.
- `screenshots/`: browser captures from the verified app, maintained during the final rehearsal.
- `scripts/`: timed five-minute script and speaking roles for 3, 4 or 5 members.
- `storyboard/`: shot list, narration, expected database states and recording checklist.
- `source/`: reproducible asset/deck generation source.

All personas and portrait assets are fictional. The percentages are deterministic compatibility scores on selected demo factors, not predictions of romantic success. The before/after graphic compares Ben and Chris; other candidates may sit between them in the full list.

The local deck is delivered as PPTX to keep all submission files together in the requested project repository. Text and ER nodes remain editable. SVG and Mermaid versions support further editing outside PowerPoint.

- `video/Chemistry-120s-storyboard-draft.mp4`: verified 120-second screenshot storyboard, with CRUD captions. It is not a live recording and has no narration. Use it to rehearse; record the final interaction video using the checklist.
